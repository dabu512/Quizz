🔌 Kết Nối Supabase Database

Nhập thông tin kết nối Supabase của bạn dưới đây. Dữ liệu câu hỏi sẽ được tải trực tiếp từ Supabase. Nếu để trống, hệ thống sẽ chạy ở chế độ Offline (sử dụng đề N3 12/2024 tích hợp sẵn).

Khuyên dùng khi tải câu hỏi lên DB nếu database của bạn chặn quyền ghi của Anon key.

🔒 Cấu Hình Quyền Ghi Database (Supabase RLS)

Theo mặc định bảo mật của Supabase, khóa anon công khai chỉ có quyền đọc (SELECT). Để chức năng đẩy câu hỏi trực tiếp hoạt động với anon key, bạn chỉ cần sao chép đoạn mã SQL dưới đây và chạy trong mục SQL Editor trên trang quản trị Supabase:

Hoặc cách đơn giản hơn: Bạn có thể lấy service_role secret key trong Project Settings -> API của Supabase và điền vào ô "Supabase Service Role Key" trong phần Cài đặt kết nối.
